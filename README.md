# لمحة | LAMHA

منصة ليبية: بطاقات دفع افتراضية، شحن ألعاب وكروت رقمية، وطلبات SHEIN.

- الواجهة: HTML/JS على GitHub Pages (الدومين الحالي في `CNAME`).
- السيرفر: `worker.js` على Cloudflare Workers (`wrangler.toml`) مع Firestore وD1 وKV.
- `index.js`: Firebase Functions للأدوار والتدقيق ودورة حياة المستخدم فقط (المال كله في الـ Worker).
- الأسرار تُضبط من لوحة الأدمن، ولا تُخزَّن في الملفات.

## الاختبارات
```
cd tests
for t in *.test.js; do node $t; done
```

## بعد النشر
1. لوحة الأدمن ← «دمج المحافظ»: اختر المحفظة الهدف ثم معاينة ← تحويل ← تفعيل.
2. جرّب طلب SHEIN بالمحفظة وبالدفع الفوري.
